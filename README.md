# STS2 - Hollow Knight Visual Mod (小骑士与前辈 视觉替换 Mod)

极其华丽的《杀戮尖塔 2》视觉替换 Mod，将游戏中的角色（死灵法师 Necrobinder）极其完美地替换为来自圣巢的无名容器（小骑士）与纯粹容器（前辈）。

## ✨ 核心特性 (Features)
* **全套视觉替换**：细致地替换了角色的战斗动画、UI 头像与状态栏图标。
* **沉浸式房间演出**：
  * **商店 / 假商人**：生动的独立思考动画。
  * **篝火休息**：极其浪漫的专属休息演出，前辈将陪伴你一同查阅地图。
* **动态选人界面**：极其霸气的专属高清大立绘与定制背景故事。
